# Prototipo Centro Médico Galenos

Versión 0.1.0. Prototipo local de los cinco perfiles del SGMG, basado en el Informe N.º 2 del grupo 2. Se conserva la identidad visual y la imagen original del proyecto.

## Abrir y revisar

1. Abre **Prototipo Centro Médico Galenos.html**.
2. Elige **Abrir aplicación** para navegar o **Leer documentación** para revisar alcance, Scrum, historias, pruebas y entrega.
3. Selecciona un perfil y pulsa Ingresar. Contraseña común de demostración: **Galenos2026!**
4. Para una nueva revisión, el botón **Preparar datos de demostración de hoy** reinicia los datos locales después de confirmarlo.

No requiere instalación para el recorrido normal. Si tu navegador limita funciones de un archivo local, el servidor opcional se inicia con Node.js mediante `node herramientas/servidor.cjs` desde esta carpeta y se abre la dirección local que imprime.

## Contenido del paquete

- **Aplicacion**: pantallas, estilos, reglas y datos iniciales de demostración.
- **Documentacion**: documentación HTML, Markdown, backlog y trazabilidad CSV, y contrato inicial de API.
- **Pruebas**: suite de negocio y resultado de ejecución.
- **Evidencias**: capturas reales de los recorridos comprobados.
- **Moqups**: mapa de páginas e interacciones para trasladar la maqueta.
- **Fuentes**: referencias académicas compartidas y nota de procedencia. Los originales internos se conservan localmente.
- **Presentacion**: visor de diapositivas para el navegador; el PowerPoint editable también está disponible.
- **Presentacion_Galenos_Review_y_Retrospectiva.pptx**: presentación editable para preparar el cierre; completar aceptación, retroalimentación y retrospectiva con el equipo.

## Estado y límites

El prototipo representa los diecinueve RF del informe actual. El backlog conserva veintitrés historias y noventa y nueve puntos; HU-4-7 se incorpora como pendiente de estimar. La fórmula usa hora base por especialidad por porcentaje del médico.

Los datos, correos, validación de bonos y segundo factor son de demostración. La aplicación guarda datos en este navegador; no tiene un servidor de producción ni certifica carga, disponibilidad, seguridad completa o cumplimiento jurídico. No se deben introducir datos reales.

La guía académica exige un enlace de Moqups. Ese proyecto externo y el enlace de AVA siguen pendientes; la versión local y el mapa de interacciones son una base para construirlos. La revisión independiente del código y la aceptación del PO deben completarse con el equipo.
